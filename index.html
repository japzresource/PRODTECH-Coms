PRODTECH COMMS

PRODTECH Comms is the operator’s command center for church and event production. Departments such as Audio, Visual, Lighting, Broadcasting and Networking hop between private call channels, follow the live Program Proper, and receive the operator’s cues on which segment is running and what comes next.

01
Channels
Each department call has its own code and password.
02
Program Proper
One shared list of segments and delegates, visible to everyone in real time.
03
Segment Signals
Inside any call, the operator taps a segment to announce NOW and NEXT.
04
News Feed
Post images, a title and a release date for the whole team.

How a service runs

Operator logs in→Opens dashboard→Joins channels→Signals segments→Service flows
